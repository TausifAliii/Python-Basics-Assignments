# Assignment 5 - Exploratory Data Analysis

## Overview

This assignment focuses on exploring a dataset related to fetal health indicators. The main goal is to understand the structure of the data, identify patterns, and study relationships between different variables. The analysis is performed step by step using simple explanations so that even a non-technical person can understand the process clearly.

## Dataset

- Cardiotocographic.csv

## Tasks Performed

- Loaded and understood the dataset structure
- Handled missing values to ensure data consistency
- Generated statistical summaries to understand data distribution
- Created visualizations such as histograms and boxplots
- Used heatmaps to study relationships between variables
- Applied pair plots to explore patterns across multiple features

## Key Insights

- The dataset shows variation in different fetal health indicators
- Some variables are closely related, indicating possible influence on each other
- A few extreme values are present, which may affect analysis
- Visualization helps in understanding patterns more clearly than raw data

## Conclusion

This assignment helped in understanding how to explore and analyze data step by step. The use of simple explanations and visualizations makes the data easier to understand. This process is useful for preparing data for further analysis or decision-making.
