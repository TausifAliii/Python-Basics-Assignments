# Assignment 6 - Hypothesis Testing and Confidence Interval

## Overview

This assignment covers two important statistical concepts: Hypothesis Testing and Confidence Interval. Both concepts are used to analyze data and make decisions based on sample information. The explanations are written in a simple and clear manner so that even a non-technical person can understand the process.

---

## Part 1: Hypothesis Testing

### Objective
The objective of this part is to check whether the existing cost model used by the company is accurate or not.

### Explanation
A cost formula is given to estimate weekly operating cost. However, restaurant owners believe that the actual cost is higher. To verify this claim, hypothesis testing is used. Two assumptions are made: one assumes that the model is correct, and the other assumes that the cost is higher. Using sample data, a test statistic is calculated and compared with a critical value. Based on this comparison, a decision is made to accept or reject the model.

### Conclusion
The analysis shows that the calculated value is significantly different from the expected value. Therefore, the existing model is not accurate, and the claim that costs are higher is supported.

---

## Part 2: Confidence Interval

### Objective
The objective of this part is to estimate the average durability of print-heads using sample data.

### Explanation
Since testing print-heads destroys them, only a small sample is used. A confidence interval is calculated to estimate the range in which the true average lies. First, the mean and standard deviation are calculated. Then, a confidence interval is constructed using the t-distribution because the sample size is small. Another interval is calculated using the Z-distribution when population standard deviation is known.

### Conclusion
The confidence interval provides a range of values where the true average durability is likely to fall. This method helps in making reliable decisions even with limited data.
