# Monthly Milk Production Forecasting using RNN, LSTM, and GRU

## Overview

This project focuses on forecasting monthly milk production using deep learning models. The dataset contains historical milk production values recorded over time. The goal is to build models that can learn patterns from past data and predict future production values.

---

## Business Objective

The objective of this project is to help dairy businesses predict future milk production. Accurate forecasting helps in planning inventory, managing supply chains, optimizing workforce, and making better business decisions.

---

## Problem Statement

The dataset contains monthly milk production values. The task is to use historical data to predict future production. This is a time series forecasting problem where the sequence and order of data are important.

---

## Dataset Information

* Time-based dataset (monthly records)
* Contains milk production values
* Used for time series forecasting

---

## Approach

The project follows these steps:

1. Load and understand the dataset
2. Perform exploratory data analysis
3. Scale the data using normalization
4. Create sequences (time windows)
5. Split the data into training and testing sets
6. Build RNN, LSTM, and GRU models
7. Train and evaluate the models
8. Compare model performance
9. Forecast future values

---

## Models Used

* RNN (Recurrent Neural Network)
* LSTM (Long Short-Term Memory)
* GRU (Gated Recurrent Unit)

---

## Evaluation Metrics

* RMSE (Root Mean Squared Error)
* MAE (Mean Absolute Error)

These metrics help measure how close the predictions are to actual values.

---

## Results

The models were trained and tested on the dataset. LSTM and GRU models performed better than the basic RNN model, as they can capture long-term dependencies more effectively.

---

## Conclusion

This project demonstrates how deep learning models can be used for time series forecasting. The models were able to learn patterns in the data and make accurate predictions, which can be useful for real-world business planning.
